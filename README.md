# Simple Kociemba
This is a Python translation of an implementation that I made of Kociemba's Algorithm in C.\
It includes:
* All the code in one file
* Partial commenting to explain how the algorithm works
* Links to external resources to learn more

It does not include:
* Any implementation of symmetries
* Sub-optimal Phase 1 searches to find shorter overall solutions
* Serialisation of look-up tables

This is designed to teach just the foundations of Kociemba's Algorithm - happy solving!
